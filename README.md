# HealthConnect Week 5 – Data Analytics

## AnalystLab Africa Experience Lab

### Project: HealthConnect Clinic

## Project Overview

This repository contains my Week 5 Data Analytics work for the AnalystLab Africa Experience Lab HealthConnect project.

The HealthConnect project focuses on understanding appointment attendance patterns and identifying factors associated with missed appointments. The overall project question is:

> How can HealthConnect Clinic use data and AI to reduce missed appointments and improve the patient support experience?

During Week 5, the project moved from planning and problem definition into practical data analysis and initial implementation.

---

## Week 5 Objectives

The objectives for Week 5 were to:

- Prepare and inspect the HealthConnect appointment dataset.
- Review data quality and relevant variables.
- Conduct Exploratory Data Analysis (EDA).
- Develop meaningful Key Performance Indicators (KPIs).
- Analyse appointment attendance and no-show patterns.
- Create an interactive Power BI dashboard.
- Identify key business insights and recommendations.
- Document limitations, risks and dependencies.

## Dataset

The analysis was conducted using the HealthConnect Appointment Dataset provided as part of the AnalystLab Africa Experience Lab.

The dataset contains fictional and anonymised appointment records, including:

- Patient demographics
- Appointment details
- Booking information
- Previous appointment history
- Previous no-shows
- Reminder information
- Distance to clinic
- Waiting time
- Appointment outcomes

The original project dataset was not modified or overwritten.

---

## Key Performance Indicators

The following KPIs were developed:

| KPI | Result |
|---|---:|
| Total Appointments | 5,000 |
| No-Shows | 2,423 |
| Attended Appointments | 2,314 |
| Cancelled Appointments | 263 |
| No-Show Rate | 48.46% |

---

## Key Findings

### 1. High No-Show Rate

The analysis found a no-show rate of **48.46%**, with **2,423 out of 5,000 appointments** resulting in no-shows.

### 2. No-Shows Slightly Exceeded Attended Appointments

The number of no-shows was slightly higher than the number of attended appointments, highlighting appointment attendance as an important area for further investigation.

### 3. Appointment Outcomes Vary Across Categories

The analysis explored appointment outcomes across:

- Age groups
- Gender
- Appointment days
- Appointment types
- Reminder channels

### 4. Operational Factors Were Explored

Waiting time and distance to the clinic were analysed across appointment outcomes.

### 5. Previous Appointment History May Be Useful

Previous no-show history was explored as a potential area for further investigation.

## Dashboard

An interactive Power BI dashboard was developed to analyse:

- Appointment outcomes
- No-shows by age group
- Outcomes by appointment day
- Outcomes by gender
- Outcomes by appointment type
- Outcomes by reminder channel
- Average waiting time by appointment outcome
- Previous no-shows
- Average distance to clinic by appointment outcome

---

## Key Recommendations

- Investigate the factors contributing to the high no-show rate.
- Calculate no-show rates across different patient and appointment categories.
- Further evaluate reminder strategies and communication preferences.
- Investigate previous appointment history as a potential indicator of attendance patterns.
- Continue monitoring operational factors such as waiting time and distance.
